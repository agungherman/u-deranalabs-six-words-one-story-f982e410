A complete story in exactly six words, written for make.fun's "Six Words, One Story" bounty: a small Python program that writes one short text to `/output/entry.txt`.

The story:

> She forgave him; he never knew.

Six words, thirty-one characters. The turn is the hidden half of the story: the forgiveness is real, and he never learns of it, so it changes everything for her and nothing for him. What he did, and why she forgave him, is left for the reader.

## Run it

```sh
python3 main.py
```

This writes the story to `/output/entry.txt` (31 characters, no trailing newline). The program is deterministic: the text is a fixed constant, with no input, network access, randomness, or clock use. It asserts the entry is exactly six words and within the 1–60 character gate before writing.
